# CRM連携の設定手順 — 予実管理システム ← crm.biglight.jp

> 一方向（CRM → 予実）。CRMには何も書き戻しません。
> **この作業をしなくても 予実 は動きます**（CSV取り込みで代替できます）。API連携にすると毎晩自動で最新になります。

---

## 何が起きるか

```
crm.biglight.jp                       finance.biglight.jp
  所属機関情報  ──┐                    取引先マスタ（CRM連携タグつき）
  特定技能者情報 ──┼─ GET /export/master ─►  特定技能者（読み取り専用）
  雇用管理      ──┘   （毎晩3:00 ＋ 手動）    在籍期間 → 支援委託料の計算根拠
```

渡すのは **予実に必要な項目だけ**です。個人番号・パスポート番号・住所・電話は渡しません。

---

## 手順（15分・CRMは止まりません）

### ① 鍵を作る

```bash
openssl rand -hex 24        # 例: 9f2c... 48文字
```

### ② CRM側にファイルを1つ足す

`crm-integration/export-master.ts` を CRMの `backend/src/exportmaster.ts` として保存。

### ③ CRMの `backend/src/index.ts` の末尾に2行足す

```ts
import { mountExportMaster } from './exportmaster'
mountExportMaster(app, pool)
```

> 既存のコードは1行も変えません。足すだけです。

### ④ CRMの `.env` に鍵を足す

```
CRM_EXPORT_KEY=<①で作った鍵>
```

### ⑤ CRMを再起動

```bash
cd /path/to/1.CRM && docker compose up -d --build backend
```

**確認**（鍵が違えば401、正しければJSONが返る）:

```bash
curl -s -H "x-export-key: <鍵>" https://api-crm.biglight.jp/export/master | head -c 300
```

### ⑥ 予実側の `.env` に接続先を書く

```
CRM_API_BASE=https://api-crm.biglight.jp
CRM_EXPORT_KEY=<同じ鍵>
```

### ⑦ 予実を再起動して「今すぐ同期」

```bash
cd /path/to/8.予実管理システム && docker compose up -d --build api
```

画面 → **マスタ › CRM連携** → 「今すぐ同期」。
取り込み結果（何社・何名・何件）が履歴に残ります。失敗した場合も理由が残ります。

## 予備の方法（API連携なしで使う）

**マスタ › CRM連携 › ツール › CSVから取り込む**。
CRMの一覧画面からCSVを出して貼り付けます。列見出しで判断するので、並び順は自由です。

| 種類 | CRMの画面 | 必要な列（見出しそのまま） |
|---|---|---|
| 所属機関情報 | 所属機関情報 | ID／所属機関名／フリガナ／法人番号／住所／電話番号／メール／分野／担当者氏名 |
| 特定技能者情報 | 特定技能者情報 | ID／特定技能者名／カタカナ／国籍／在留資格／在留期限 |
| 雇用（在籍期間） | 雇用管理 | ID／特定技能者／所属機関／入社日／退職日／雇用状況 |

> ⚠ CSVの「ID」列は CRM内部のIDです。同じ会社を二重に作らないための鍵なので、必ず含めてください。

---

## 取り込み後のデータの扱い

| 項目 | 誰のもの | 同期で上書き |
|---|---|---|
| 会社名・住所・電話・担当者・分野 | CRM | ✅ 毎回上書き |
| 締日・支払サイト・支払日・口座・与信 | **予実（手入力）** | ❌ 絶対に触りません |
| 請求ルール（単価・人数の数え方） | **予実（手入力）** | ❌ |
| 特定技能者・在籍期間 | CRM | ✅ |

CRMに無い会社（仕入先・外部の取引先）は 予実 に直接追加します。
一覧では「CRM連携／手入力」のタグで見分けられます。

CRM側で会社や人が消えた場合、予実では**削除せず「CRM消失」の印**を付けます。
過去の請求書からその会社・その人を辿れなくなると困るためです。
